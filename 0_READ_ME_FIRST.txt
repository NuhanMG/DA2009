------------------------------------------------------------------
 BEFORE YOU START - is the project unzipped?
------------------------------------------------------------------
If you are reading this from inside a ZIP file, stop here first:
  1. Go to your Downloads folder.
  2. Right-click  DA2009-main.zip
     and click  Extract All...  then click  Extract.
  3. Open the new folder, and then the folder inside it with the
     same name. Open this file again from there.


------------------------------------------------------------------
 THE FIRST TIME ONLY
------------------------------------------------------------------
  1. Double-click   1_SETUP_First_Time_Only
  2. A black window opens. That is normal.
     - If Windows says "Windows protected your PC":
       click  More info  and then  Run anyway.
     - If Windows says "Open File - Security Warning": click  Run.
  3. If it asks "Install Python 3.12 now?"  press  Y
  4. Wait 5 to 15 minutes (longer on slow internet). Lots of text
     scrolls past - that is normal. Do not close the window.
  5. If it asks "Install Tesseract now?"  press  Y
     When Windows asks "Do you want to allow this app to make
     changes to your device?"  click  Yes.
  6. When the window turns GREEN and says ALL DONE, press any key.

  If the window turns RED, read what it says - it tells you what
  to do. Running 1_SETUP_First_Time_Only again fixes most problems.


------------------------------------------------------------------
 EVERY TIME YOU WANT TO USE THE APP
------------------------------------------------------------------
  1. Double-click   2_START_The_App
  2. Your browser opens the app by itself after 10 to 20 seconds.
     If it does not, type this into your browser's address bar:
         http://127.0.0.1:7860
  3. KEEP THE BLACK WINDOW OPEN while you use the app.
  4. To stop the app, close the black window.
